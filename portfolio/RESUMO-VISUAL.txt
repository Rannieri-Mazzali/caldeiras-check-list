🚀 COMEÇAR AGORA (3 PASSOS)
════════════════════════════════════════════════════════════════════

PASSO 1: Editar Valores (5 minutos)
─────────────────────────────────────
  📄 Abra: portfolio/config/plans.ts
  ✏️  Preencha os preços:
     - monthlyPrice: 99 (ex: R$ 99)
     - setupPrice: 500 (ex: R$ 500)
  💾 Salve

PASSO 2: Testar Localmente (5 minutos)
─────────────────────────────────────
  🖥️  Terminal: cd portfolio
  ⚙️  Execute: npm run dev
  🌐 Abra: http://localhost:3001
  🔍 Verifique os preços
  ⏹️  Parar: Ctrl+C

PASSO 3: Fazer Deploy (5 minutos)
─────────────────────────────────────
  🌐 Opção A (Windows): deploy.bat
  🌐 Opção B (Mac/Linux): deploy.sh
  🌐 Opção C (Manual): vercel deploy --prod
  ✅ Pronto! Seu site está online!
